# Contributing

Thanks for contributing to scim-app-policy.

This repository contains the privacy policy and terms of service pages
served via GitHub Pages for the SCIM Sandbox project. Keep changes
focused on policy content, HTML structure, or documentation that
matches the live deployment.

## Ground Rules

- Keep each change narrow and intentional.
- Do not mix unrelated refactors into policy content changes.
- Keep policy language clear and accurate.
- Update docs when the deployment or page structure changes.

## Before You Start

1. Check for existing issues or pull requests that already cover the same work.
2. Read [README.md](./README.md) before changing policy content.
3. If the change modifies legal language, ensure the update is reviewed by the project maintainer.

## Validation

Validate changes before opening a PR.

Common checks:

- open the HTML files locally in a browser to verify rendering
- check for broken links or formatting issues
- verify the page structure matches the GitHub Pages deployment expectations

## Pull Request Checklist

- explains the policy or structural change and why it is needed
- updates docs if the deployment process changes
- avoids unrelated cleanup
- passes the relevant validation steps

## Reporting Bugs

When reporting a policy page issue, include:

- the affected page (privacy or terms)
- the browser and version
- the expected and actual rendering
- a screenshot if relevant

## Security Issues

Do not report vulnerabilities through public issues.

Follow [SECURITY.md](./SECURITY.md) instead.
